# pairwise-inventory-transaction

两个玩家同时点确认交易，物品在两边背包里各留了一份，事务只锁了发起方，接收方的背包在另一个服务里没有参与同一个锁；扣物品与加物品分成两次写，中间崩溃后一边扣了另一边没加；重复点击确认生成两个事务 id，幂等键只用了玩家 id；堆叠拆分时按数量复制，拆分失败没有回滚源堆叠；交易中的物品被另一个系统强化后属性变了，结算用的是新属性；邮件补发绕过了事务，离线玩家上线后收到两份；回滚按操作日志倒序执行，但日志里没有记录随机附魔结果；两个事务交叉锁背包和银行，死锁检测超时后双双失败却都扣了手续费；审计日志只记录成功事务，失败事务的中间状态无法复现；客户端本地先加物品做预览，服务器拒绝后客户端没收到回滚。gameplay/inventory_transaction.py 是核心，tests/test_inventory_transaction.py 15个红。要修的是：双端同一事务；单次原子写；幂等键含双方；拆分失败回滚；结算锁定快照；邮件入事务；日志含随机结果；锁顺序统一；失败也记审计；客户端以服务器为准。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
